# Audit identities

The user filter displays the current account name and actual `@username`. Historical entries from removed accounts retain their recorded name and a Former account label. Missing names use a localized neutral label; internal IDs are retained only as filter values.

Selecting an actor continues to filter by the immutable account ID, including when accounts share a name or a profile has since been renamed. The separate System / Unattributed option retains its existing behavior.
