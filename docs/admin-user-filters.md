# Users and roles filtering

Open Role, Tutor Status or Account to include and exclude several values. A row may match any included value within one filter, but must satisfy every filter. Exclusion always wins, even if the same value is also included. An empty include list allows all values except exclusions.

**No account role** and **No linked tutor** identify unlinked records explicitly. The result count shows how many rows remain; **Clear filters** restores all rows. Each signed-in account's filters are remembered in the current browser and restored after reload. Restricted browser storage does not prevent filtering during the current visit.
