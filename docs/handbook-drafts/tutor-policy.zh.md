# 导师参与手册

学校审核草案 · 2026年9月9日

## 辅导与出勤

使用分配给自己的学生名单，如实报告课次情况。提交出勤前须接受当前导师政策。管理人员更正历史记录时须提供理由，并保留审计快照、通知 HEAD。协调员的更正须经 ADMIN 或 HEAD 批准后生效。

同一项目周期内的计划教室安排不得重叠，前后相接的时段允许使用。若历史课次确实在存在安排冲突的教室发生，应如实报告；系统会提示、记录冲突并通知管理人员。这不构成未来重叠预订的授权。

学生修改可用时间造成冲突时，可提交附理由的时间冲突申请。批准前现有安排继续；批准后仅解除该安排，学生保留原优先级重新匹配，验证期限不重置。

## 导师会议与服务时长

会议请假须在开始前至少60分钟提交。获准请假的缺席不计入无故缺席次数。

同一学年 Q1 和 Q2 为第一学期，Q3 和 Q4 为第二学期。每学期前三次无故会议缺席不自动扣时，此后每次扣除0.25服务小时。该规则取代旧的每次0.125小时扣时规则。更正记录会重新计算同学期后续扣时，人工调整单独保留。

已完成面试按实际记录时长向实际出席者计时；仅排期不获得时长。管理人员记录完成时间、时长和出席者并提供理由；更正会替换原自动时长，不会重复累加。

## 面试小组与决定

小组至少包含三名不同的、有账户的活跃导师；至少一名管理人员，且至少一名导师具有工作人员确认的申请科目资质。

由小组内最高管理级别成员主持：HEAD 高于 ADMIN，ADMIN 高于 COORDINATOR。同级最高管理成员有多名时，由选定的主持人负责平票决定。

所有成员投票后方可作出最终决定。多数票决定结果；平票由主持人决定。协调员主持人须将所选结果提交 ADMIN 或 HEAD 审批；审批授权该决定，不替换主持人身份或其决定。小组证据变化后须重新提交。

## 反馈、私信与发布

学生反馈默认仅管理人员可见，管理人员可允许该课次导师查看，也可撤销对已有和未来反馈的访问。私信仅对话双方可见。

指定翻译人员可准备草案，发布须经管理审核；协调员也须获得 ADMIN 或 HEAD 批准。翻译权限不包含网站结构编辑、删除或账户管理权限。
